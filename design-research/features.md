## Existing strengths to retain

12 labs, quizzes with missed-question review, guided curricula, glossary/search/categories, comparisons, playback/speed/step controls, educational accordions, input examples/feedback, local progress, dark/light/system themes, offline/PWA affordances. A catalog upgrade must complement these rather than remove them.

## Ranked safe opportunities

1. Fix dark surfaces/readability, overlapping mobile header and keyboard navigation. These are barriers to every learner.
2. Bring the live demo into the opening section; make the beginner curriculum prominent while keeping direct AES/glossary entry points.
3. Search/filter the complete topic catalog; consistent category and lesson numbering.
4. Correct stale module destinations using existing URLs; wire module progress to passed knowledge checks and honest achievements. No database changes.
5. Contextual lesson navigation, prerequisites/next steps, progress summary and resume action from existing local data.
6. Related glossary terms become actions; result count, labelled search and selected-filter semantics.
7. Footer with learning/reference/source destinations; per-route browser titles and accessible loading feedback.

No competitors were blocked during these ten key-page loads. Authenticated experiences, all subpages, paid tutoring, and advertised simulations were not exhaustively exercised. The Phase 6 browser journey checks apply to CryptoViz, not these peers.
