# CryptoViz (encryption-visualizer)

An interactive educational web app that visualizes cryptographic algorithms step by step:
AES-128, RSA, ECC, Diffie-Hellman, hash functions, HMAC, digital signatures, padding schemes,
password hashing, TLS, and cryptanalysis, plus a glossary, quizzes, and guided learning paths.

**The real application lives in the [`encryption-visualizer/`](./encryption-visualizer)
subdirectory** - see [that README](./encryption-visualizer/README.md) for the quickstart,
scripts, and feature list, and [CLAUDE.md](./CLAUDE.md) for the full stack and layout.

This repo root only holds deploy config (`vercel.json`, `release-please-config.json`,
`renovate.json`) for the nested app; it has no `package.json` of its own.
